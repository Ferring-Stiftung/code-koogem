# code köögem
Hub for open language resources published by the Ferring Stiftung

*code köögem* ist die Open Source Initiative der Ferring Stiftung, um Entwickler*innen und anderen Interessierten einen Zugriff auf kuratierte Sprachdaten zu ermöglichen. Die in diese Repository enthaltenen Daten können entsprechend ihrer jeweiligen Lizenzen verwendet werden. Wir freuen uns über einen Hinweis über jedes veröffentlichte Projekt, das auf diese Daten zugreift.

*code köögem* is the Ferring Foundation’s open-source initiative designed to provide developers and other interested parties with access to curated language data. The data contained in this repository may be used in accordance with their respective licenses. We would appreciate being notified of any published project that uses this data.
